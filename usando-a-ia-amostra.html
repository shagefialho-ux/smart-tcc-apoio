Usando a IA 3/3 · Pergunta

Prompt pronto para o Claude gratuito

Tarefa-chave: testar a pergunta nos critérios, com um leitor exigente.

Copie e cole no Claude · claude.ai

Minha pergunta de pesquisa é: [SUA PERGUNTA]
Tema: [TEMA]. Contexto em 2 frases: [CONTEXTO].

Avalie a pergunta nos critérios: clareza; autenticidade (não é óbvia nem já respondida); exequibilidade (dá para responder com meu tempo e meus dados: [TEMPO E DADOS DISPONÍVEIS]); pertinência ao curso.

Dê nota de 1 a 5 em cada critério, justifique e proponha 3 reformulações. Antes de avaliar, faça-me até 3 perguntas se algo estiver ambíguo. Seja crítico: não elogie sem motivo.

Onde inserir seus dados

[SUA PERGUNTA]
a versão atual, com ponto de interrogação
[CONTEXTO]
resumo das partes Tema e Contexto
[TEMPO E DADOS...]
ex.: "4 meses, acesso a 20 professores"

Como usar: entre em claude.ai com conta gratuita → Novo chat → cole o prompt → troque cada [CAMPO] pelo seu conteúdo, apagando os colchetes → anexe arquivos pelo botão + → envie e revise a resposta.

Pensado para o Claude gratuito (Sonnet 5, set/2026); funciona também nos planos pagos. Nunca envie dados pessoais de participantes.
